# Heebo desktop chrome fonts

Unmodified Heebo Regular and SemiBold fonts, bundled for offline use with their SIL Open Font License (`OFL.txt`). Calculation source and results retain the system monospaced font.

Source: HedRoom `ios/App/Resources/Fonts` at commit `f8fce47e6531014d821c37ab48594591f1f411ee`. Typography follows HedRoom's `design/brand/BRAND.md`: Heebo 600 with 0.176em tracking for the wordmark. The desktop's warm dark palette follows its canonical brand sheet and `apps/web/src/app/globals.css`; the light palette is an adaptation for readable ink on warm paper.
