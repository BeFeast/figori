# Bundled Nerd Font

JetBrains Mono NL Nerd Font Mono Regular and Bold are unmodified, full-glyph TTF files from Nerd Fonts v3.5.1 (upstream JetBrains Mono 2.304). NL disables programming ligatures; Mono keeps icon advances monospaced. The application loads them offline under CSS alias Figori Nerd Mono. No system font installation is required.

Pinned official archive: https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.1/JetBrainsMono.tar.xz
Archive SHA256: 04d5e8f903693f9dd13e16f867e994834e681eb3c72c0d337a770dcda09010cf (verified against GitHub release asset digest).

See JetBrainsMono-OFL.txt for the font license, Nerd-Fonts-LICENSE.txt for the release licensing notice, and Nerd-Fonts-UPSTREAM.md for original icon-set attribution. The existing build copies this complete directory, including licenses, into dist/fonts.
